# 🗺️ Treasure Hunt AR Game (Flutter + Google Maps)

**Developed by Afaq Ahmad**

An interactive **Treasure Hunt Augmented Reality (AR) game** built with Flutter and Google Maps. This app allows users to explore real-world locations, discover hidden treasures, and experience gamified navigation.

---

## 🌟 Features

* 🗺️ Real-time map integration using Google Maps
* 📍 Location-based treasure markers
* 🎯 Interactive treasure hunt gameplay
* 📱 Clean and simple UI
* 📸 AR View screen (extendable for ARCore / ARKit)
* 🚀 Smooth navigation between map and AR mode

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/afaqahmad/treasure-hunt-ar-game.git
```

2. Navigate into the project:

```bash
cd treasure-hunt-ar-game
```

3. Install dependencies:

```bash
flutter pub get
```

4. Add your Google Maps API key:

* Android: `android/app/src/main/AndroidManifest.xml`
* iOS: `ios/Runner/AppDelegate.swift`

5. Run the app:

```bash
flutter run
```

## 🎮 How It Works

* The map loads with predefined treasure locations
* Users explore the map and find markers
* Clicking markers reveals treasure info
* AR mode can be launched for immersive experience (future scope)
